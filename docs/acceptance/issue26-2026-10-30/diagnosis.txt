In this runtime, direct execution of a newly created executable fails with PermissionError [Errno 13] (noexec-like execution restriction). BASH_ENV and ENV were unset. Helper stdout and stderr were both empty, return code 0: find -exec does not run the inaccessible fake commands, so MOCK_LOG is never created. This explains the two empty-log assertions and the repeated-startup test's FileNotFoundError.

The execution restriction was independently reproduced for a script created under /share as well as /tmp, so setting TMPDIR would not fix this runtime.
